# 小智 ESP32-S3-ePaper-3.97 SD卡学习版 — 编译与使用说明（2026-09-01 版）

## 一、功能总览

基于官方 [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) @ bb9122a（板型 `waveshare/esp32-s3-epaper-3.97`）：

| 功能 | 说明 |
|---|---|
| SD 卡读写 | 板载 SDMMC 卡槽，CLK=16 CMD=17 D0=15 D1=7 D2=8 D3=18，20MHz，4线→1线两级重试 |
| 本地知识库检索 | 词条索引常驻内存、原文按需从 SD 卡读取（16 槽 LRU 缓存，容量 8000 条）；MCP 工具 `self.kb.search`，本地优先 |
| 异常回退 | 未插卡/读写异常/未命中时返回内部信号 NO_LOCAL_HIT，LLM 静默改用网络知识，不向学生提及 |
| 对话记录 | user/assistant 对话自动追加到 `/sdcard/chatlog/YYYYMMDD.txt`（时间未同步时入 `unknown_date.txt`） |
| 学习打卡 | `self.study.checkin` 打卡、`self.study.review` 回顾明细、`self.study.summary` 统计，存 `/sdcard/study/` |
| 错题本 | 权重评分：新增5，再错+2（上限10），答对−2，连续答对3次或权重≤0自动移出 |
| 学习计划 | 语数英每天各3条；`/study/plan_config.txt` 可手动编辑或语音修改（"把数学改成每天5条"） |
| 加权随机抽题 | 词条出现次数计数（`entry_counts.txt`），低频次优先，降低重复推送 |
| 课程表 | 开机常驻 3 列显示（今天/明天/后天），数据来自 `/schedule/schedule.txt`；周末自动回绕到下周一 |
| 每日一句 | 屏幕中部常驻；联网后自动从本地资料库抽取，跨天自动更换 |
| 动态刷新 | **WiFi 连接成功 / 时间刚同步 / 跨天时自动刷新课程表和每日一句**（0901 新增） |
| 显示 | 底部聊天区固定 2 行换行显示（超出以"…"截断）；课程表/每日一句用板级定制 24px 字体（`font_xiaozhi_study_24.c`），其余界面全局 20px |

## 二、获取源码（三种方式，任选其一）

> ⚠️ **工程路径不能含中文或空格！** ESP-IDF 工具链会把非 ASCII 路径错误转码
> （报错形如 `cannot read spec file '...\x0a.../nano.specs'`）。

**方式 A：合并好的完整源码（推荐，最省事）**

解压 `xiaozhi-esp32-bb9122a-study-merged_20260901_1453.zip`，得到
`xiaozhi-esp32-bb9122a-study/`（= 官方 bb9122a + 本项目全部改动，共 1671 个文件），
直接进入下面的「三、编译」。

**方式 B：完整差异补丁（适合自己同步了上游的情况）**

```bash
git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32
git checkout bb9122a
git apply /路径/xiaozhi-esp32-bb9122a-study-full-diff_20260901_1453.patch
```

补丁共 20 个文件（+38112 / −115 行）：修改 6 个（main/CMakeLists.txt、
main/display/lcd_display.cc、板级 config.h/config.json/custom_lcd_display.h/.cc/
waveshare-s3-epaper-3.97.cc），新增 14 个（板级 6 大模块 + font_xiaozhi_study_24.c）。
已在干净的 bb9122a 树上 `git apply --check` 验证可无损应用。

**方式 C：手动覆盖**

获取官方源码 `git checkout bb9122a` 后，把本归档 `firmware/main/` 下的文件
**按相同路径覆盖**进源码树。

## 三、编译步骤

1. 安装 ESP-IDF（v5.5.x 或 v6.x，与官方 README 一致）。
2. 编译（推荐用官方脚本，自动合并 config.json 的 FATFS 配置）：
   ```bash
   python3 scripts/build.py waveshare/esp32-s3-epaper-3.97
   ```
   手动 `idf.py build` 必须先 `idf.py menuconfig`：
   - `Xiaozhi Assistant → Board Type` = **Waveshare ESP32-S3-ePaper-3.97**
   - `Component config → FAT Filesystem support`：
     `Long filename support` = **Long filenames on heap**，`Max long filename length` = **255**，
     `API character encoding` = **UTF-8**，`Number of simultaneously open files protected` = **2**
   漏掉 FATFS 配置会导致中文文件名退化为 8.3 短名、资料库解析为 0 条。
3. 烧录：`idf.py flash monitor`（或 `python3 scripts/flash.py`）。
   烧录前确认 `build/generated_assets.bin` 已生成（assets 资源分区，构建 100% 成功才会有）；
   若 flash 报 `No such file or directory: 'generated_assets.bin'`，说明构建未完成，回去重新构建即可。
   板级 24px 字体（font_xiaozhi_study_24.c，约 310KB）已编进固件，正常构建即可；
   若链接报 app 分区溢出，联系维护方重新生成 bpp=1 版本字体。

## 四、SD 卡准备

详见《SD卡使用说明.md》。要点：FAT32 格式化；把归档 `sdcard/` 下的
`knowledge/`、`prompt/`、`study/`、`schedule/` 四个文件夹整体拷到 SD 卡根目录；
插卡开机，串口应出现 `SD card mounted` 与词条加载数量。

## 五、服务端（小智控制台）配置

把 `sdcard/prompt/角色设定提示词（粘贴到小智控制台）.txt` 的内容粘贴到
[xiaozhi.me](https://xiaozhi.me) 控制台对应智能体的"角色设定/提示词"中，
强化"优先本地资料库"的行为习惯。

## 六、日常使用

- 学生按《小智20天学习口令表》念口令即可；答完题小智自动打卡。
- 问课程："今天有什么课" / "明天第几节是数学"（触发 `self.schedule.today`）。
- 家长更新课程表文件后，对小智说"刷新课程表"（触发 `self.schedule.reload`）。
- 学生说"换一句"更换每日一句（触发 `self.quote.refresh`）。
- 更新资料库：新 txt 拷入 `/knowledge/`，说"重新加载资料库"（`self.kb.reload`）。
- 对话记录、打卡、错题在 SD 卡 `chatlog/`、`study/`，可定期取出交给
  Kimi 的 **xiaozhi-study-kb** 技能分析并优化下一轮口令表。

## 七、设备端 MCP 工具（19 个）

| 工具 | 作用 |
|---|---|
| `self.kb.search` | 检索本地资料库（query、max_results 1-5），未命中静默回退网络知识 |
| `self.kb.status` | 查询 SD 卡与资料库状态（文件数、词条数） |
| `self.kb.reload` | 更新资料库后重新加载，免重启 |
| `self.kb.daily` | 随机一条词条（对话内"每日一句"推送） |
| `self.study.checkin` | 学习打卡（结果含"错"自动进错题本） |
| `self.study.mistake` | 记录错题（权重：新增5，再错+2，上限10） |
| `self.study.correct` | 错题答对（权重−2，连对3次移出） |
| `self.study.mistakebook` | 查看错题本（按权重降序） |
| `self.study.plan` | 查看学习计划 |
| `self.study.set_plan` | 语音修改计划条数（1-9，单科或全部） |
| `self.study.review` | 最近 N 天打卡明细 |
| `self.study.summary` | 最近 N 天打卡统计 |
| `self.schedule.today` | **查看课程表**（今天/明天/后天/周几，0901 新增） |
| `self.schedule.reload` | **重载课程表并刷新屏幕**（0901 新增） |
| `self.quote.refresh` | **更换每日一句并刷新屏幕**（0901 新增） |
| `self.sd.ls` | 查看 SD 卡目录内容（含文件大小） |
| `self.sd.remount` | 重新挂载 SD 卡并重载资料库、课程表 |
| `self.sd.read` | 读取指定文件开头内容（检查内容/编码） |
| `self.disp.network` | 重新配网 |

## 八、常见问题速查

完整版见技能 **xiaozhi-esp32-troubleshooting** 的 references/problem_history.md。

| 现象 | 处置 |
|---|---|
| `-Werror=comment` | 注释里不要写 `/*.txt` 这类含 `/*` 的片段 |
| `-Werror=format-truncation` | snprintf 缓冲区按 GCC 最坏情况调大 |
| bread-compact-wifi 初始化报错 | 板型没选对，必须选 Waveshare ESP32-S3-ePaper-3.97 |
| `nano.specs` 转码报错 | 工程路径改纯 ASCII + 删 build 目录重编 |
| 扫不到 SD 卡 | 已内置：降频 20MHz、重试间 `sdmmc_host_deinit()`、空目录扫根目录、跳过 `._` 文件 |
| 挂载成功但 0 词条 | 手动 idf.py build 不合并 config.json，需 menuconfig 自开 FATFS UTF-8 长文件名 |
| SPI DMA 内存不足 | 词条原文已迁 PSRAM / 动态加载，勿改回内部 RAM |
| `'StudyManager' has not been declared` | 板级 .cc 补 `#include "study_manager.h"` |
| 链接报 `EPD_*` 未定义 | custom_lcd_display.cc 被残缺文件整体覆盖；该文件是墨水屏驱动本体，只许追加不许整体替换 |
| `SD_MOUNT_POINT` was not declared | schedule_manager.h 必须先 `#include "config.h"` 再使用该宏 |
| Guru Meditation（InstrFetchProhibited，LVGL 字体） | 检查 label 空指针与 UTF-8 截断边界；本版已加防护 |

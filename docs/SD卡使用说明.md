# 小智学习机 SD 卡使用说明（2026-09-01 版）

## 一、准备

1. SD 卡格式化为 **FAT32**（≤32GB 直接格式化；>32GB 用工具强制选 FAT32）。
2. 把本归档 `sdcard/` 下的 4 个文件夹整体拷到 SD 卡**根目录**（已有旧文件直接覆盖）：
   ```
   /knowledge/   学习资料库（人工维护）
   /prompt/      提示词与口令表（备份，供家长查看）
   /study/       学习计划配置 + 设备自动生成的打卡/错题数据
   /schedule/    课程表
   ```
3. 插卡开机。串口日志应出现 `SD card mounted` 和词条加载数量；
   未插卡也能用，只是全部走网络知识（学生侧无感知、无任何提示）。

## 二、目录与文件格式

```
/sdcard
├── knowledge/                  资料库 txt（UTF-8，可多个文件）
│   ├── 小学语文学习资料库.txt       221 条
│   ├── 小学数学学习资料库.txt       104 条
│   ├── 小学英语学习资料库.txt        91 条
│   ├── 小学语文常用1000字解析资料库.txt 1000 条（识字）
│   ├── 小智历史学习资料库.txt        65 条
│   └── 小智科学学习资料库.txt        44 条（合计 1525 条）
├── prompt/                     提示词备份（设备不读，仅家长用）
│   ├── 角色设定提示词（粘贴到小智控制台）.txt
│   ├── AI小智学习提示词速查卡.txt
│   └── 小智20天学习口令表.txt
├── study/
│   ├── plan_config.txt         学习计划配置（人工/语音可改）
│   ├── checkin_YYYYMMDD.txt    每日打卡记录（设备自动）
│   ├── mistakebook.txt         错题本（设备自动维护）
│   ├── mistakes.txt            错题流水（设备自动，只增不删）
│   └── entry_counts.txt        词条出现次数（设备自动）
├── schedule/
│   └── schedule.txt            课程表（人工维护）
└── chatlog/
    ├── YYYYMMDD.txt            每日对话记录（设备自动）
    └── unknown_date.txt        时间未同步时的对话记录
```

### 1. 资料库词条格式（knowledge/*.txt）

```
【编号】YW-MR-001
【类别】名人名言-学习类
【关键词】学习、勤奋、练习
【内容】书山有路勤为径，学海无涯苦作舟。
```

- 必填：编号、类别、关键词 + 至少一个内容字段；可选字段任意命名（出处/启示/拼音/造句…）。
- 编号规则：`^(YW|SX|EN)-[A-Z]+(-[A-Z])?-\d{2,3}$`（YW语文/SX数学/EN英语）；
  编号行可带"★必背"等后缀，固件只取第一个词。
- **关键词要写全**：动态加载方案里关键词是主要检索信号，纯靠原文命中可能不被召回。
- 文件名中英文均可，UTF-8 编码；扩展名忽略大小写；macOS 的 `._` 垃圾文件自动跳过。
- `/knowledge/` 为空时固件会自动扫描根目录及一级子目录中含 `【编号】` 的 txt。
- 更新后对小智说"**重新加载资料库**"即生效，无需重启、无需改固件。
- 新增资料库前先用 xiaozhi-study-kb 技能的 `validate_kb.py` 校验（格式/编号/重复/内容拦截）。

### 2. 学习计划配置（study/plan_config.txt）

```
# 每科每天学习内容条数（1-9）；all 为统一配置，单科配置优先于 all
all=3
chinese=3
math=3
english=3
```

- 科目键：`chinese` / `math` / `english` / `history` / `science` / `all`；本包 plan_config 已含历史/科学（每天各 1 条），可语音修改（如"把历史改成每天2条"）。
- 修改途径：① 电脑直接编辑；② 语音："把数学改成每天5条"（`self.study.set_plan`，立即生效并落盘）。

### 3. 课程表（schedule/schedule.txt）

```
# 格式：星期|节次|科目|备注     （# 开头为注释行）
# 星期：1=周一 … 5=周五；节次：0=早读 1-6=第一~六节
1|1|英语|
1|2|语文|
2|1|数学|带口算本
```

- 竖线分隔，备注可留空；顺序无关（固件自动按星期+节次排序）。
- 屏幕开机常驻 3 列：今天/明天/后天；**周五自动回绕显示下周一、周二**。
- 更新文件后：对小智说"**刷新课程表**"（`self.schedule.reload`）立即生效；
  或者重新插拔 SD 卡后说"重新挂载SD卡"（`self.sd.remount`）。
- 时间未同步时屏幕显示"时间未同步"，**联网成功后自动刷新恢复**（0901 起，无需任何操作）。

### 4. 打卡记录（study/checkin_YYYYMMDD.txt）

CSV 行：`HH:MM:SS,科目,学习内容,结果`；结果含"错"字自动进错题本。

### 5. 错题本（study/mistakebook.txt）

行格式：`键|权重|累计答错|连续答对|最近描述`。
权重：新增5、再错+2（上限10）、答对−2；连续答对3次或权重≤0自动移出。

### 6. 对话记录（chatlog/）

`[HH:MM:SS] user: ...` / `[HH:MM:SS] assistant: ...`；时间未同步写入 `unknown_date.txt`。

## 三、常用语音指令速查

| 学生/家长说 | 触发工具 |
|---|---|
| 重新加载资料库 | self.kb.reload |
| 今天/明天有什么课 | self.schedule.today |
| 刷新课程表 | self.schedule.reload |
| 换一句（每日一句） | self.quote.refresh |
| 把数学改成每天5条 | self.study.set_plan |
| 查看错题本 / 复习错题 | self.study.mistakebook |
| 最近学得怎么样 | self.study.review / summary |
| 重新挂载SD卡 | self.sd.remount |

## 四、内容边界

本设备仅用于小学语文/数学/英语学习。游戏、充值、理财、广告、隐私等
非学习内容一律不得放入资料库与提示词；整理资料时由 xiaozhi-study-kb 技能强制校验拦截。

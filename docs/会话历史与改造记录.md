## 三、关键技术结论（回溯用）

- 板型 `waveshare/esp32-s3-epaper-3.97`；SD 卡 SDMMC：CLK=16 CMD=17 D0=15 D1=7 D2=8 D3=18，挂载 20MHz，4线→1线两级重试
- 检索两阶段：①元数据打分（编号精确+1000/关键词 bigram+20 单字+6/类别 bigram+10 单字+3）取前 12 候选不读卡；②候选加载原文加全文分（bigram+4/单字+1）−出现次数×2，阈值 8
- 内存：词条原文不常驻，命中时 ReadFileRange 按偏移读取 + LRU 缓存；内部 RAM 零占用，不影响 SPI DMA
- 已知取舍：纯靠原文命中（关键词/类别/编号都不沾边）的词条不再被召回——**编写新词条关键词要写全**
- 中文文件名 FATFS 配置只有 `scripts/build.py` 会合并；手动 idf.py build 必须 menuconfig 自开 LFN_HEAP/UTF-8
- 词条编号：`^(YW|SX|EN)-[A-Z]+(-[A-Z])?-\d{2,3}$`（固件解析不限前缀；LS/KX 前缀因内容边界已随 28 号资料一并移出当前 SD 包）
- 错题本行格式：`键|权重|累计答错|连续答对|描述`；MarkCorrect 返回 1=在册/0=移出/−1=未找到
- 课程表文件 `/schedule/schedule.txt`：`星期|节次|科目|备注`，星期 1-5、节次 0=早读 1-6
- **联网自动刷新（0901）**：板级重写 `SetNetworkEventCallback` 包装原回调，Connected 时只置位
  `network_refresh_pending_`（WiFi 事件上下文不能做 SD/LVGL 操作）；后台任务 `sched_refresh`
  每 5 秒检查：刷新标记 / 时间刚同步（time ≥ 2024-01-01）/ 跨天，满足即 `ScheduleManager::Load()` +
  抽每日一句 + `UpdateScheduleAndQuote()`
- 每日一句：取 `RandomEntry()` 返回文本的【内容】字段首行，UTF-8 边界安全截断 ≤84 字节；
  资料库不可用时保留默认名言，不打扰学生
- MCP 工具（19 个）：self.kb.search/status/reload/daily；self.study.checkin/mistake/correct/
  mistakebook/plan/set_plan/review/summary；self.schedule.today/reload；self.quote.refresh；
  self.sd.ls/remount/read；self.disp.network
